# Session: Implemented Mobile Card View & Expandable Accordion for Admin Dashboard: replaced horizontal-scrolling table on mobile (<768px) with actionable cards showing essential info and instant approve/reject/return buttons, plus collapsible accordion for full contact & purpose details. Upgraded item stock to mobile cards as well while preserving full desktop tables.

## Decisions
- **Card View with instant action buttons + Expandable Accordion on mobile (<768px), full Table on desktop (>=768px)**: Horizontal scrolling tables on mobile phones create high friction. Card views allow admins to immediately view items, status, dates, and approve/reject with one tap, with secondary details expandable on demand.
