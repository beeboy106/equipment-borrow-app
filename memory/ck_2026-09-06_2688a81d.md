# Session: เพิ่มระบบกรองอิสระ Overdue และ Custom Modal Toast

## Decisions
- **สร้าง Custom ConfirmModal และ ToastContainer แทนการใช้ alert/confirm**: เพื่อให้ UI สวยงาม เข้ากับธีม และไม่บล็อกการทำงานของเบราว์เซอร์
- **เพิ่มแท็บ Overdue และตัวกรองกลุ่มผู้ใช้ในหน้า Admin**: ช่วยให้ผู้ดูแลระบบติดตามอุปกรณ์ที่เลยกำหนดคืนได้อย่างรวดเร็วและเป็นอิสระ
- **อนุญาตให้ยกเลิกคำขอได้เฉพาะสถานะ pending**: ป้องกันความสับสนและข้อผิดพลาดในการคืนสต็อกกรณีอนุมัติไปแล้ว
